Subnet Workbench — Step 8

Page Shell Mockups

Three shell layouts, each shown in Calculate mode with the same content: input panel, the 1A bit-ribbon visual slot, text results, mode hand-off actions, and the opt-in "Copy shareable link" button. The four visible mode tabs are the fixed requirement; what varies is where they live and how input, visual, and hand-off relate.

VARIANT A — COMMAND DECK

Top tab rail, two-column workspace

Nav-style parallelogram tabs (matches the site nav) across the top. Input stays pinned in a left column, results and visual fill the right, so input and output are visible side by side while iterating. Hand-off is a row of actions under the results; the share link lives in a persistent footer status bar.

VARIANT B — WORKBENCH RAIL

Left mode rail, full-width flow

Main column flows input → visual → results top to bottom, giving the visual full width. Hand-off is a chip row attached directly to the result card. Share link sits with the run controls.

VARIANT C — HUD STACK

HUD bar with segmented tabs, centered column

The portfolio-card HUD bar becomes the tool's chrome: glowing strip with the tool name left, segmented mode control center, share link right. Below it a single centered column (input, visual, results) like a focused instrument panel. Hand-off actions sit in the result card's corner. Most compact chrome of the three; tabs read as a control, not navigation.

Combinable pieces

Tab treatments, layout skeletons, and hand-off styles are independent — any tab row works with any layout.

Tabs: A parallelogram nav-tabs · B mode rail with descriptions · C segmented HUD control.
Layout: A side-by-side input/output · B full-width top-to-bottom flow · C centered narrow column.
Hand-off: A button row under results · B/C chip row on the result card (corner or bottom).
Share link: A footer status bar · B beside run controls · C in the HUD bar.
